# Northstar v8.7.2 — Release Notes

**Released:** 2026-06-28

---

## What's New

### Added

- Transactions can now be re-tagged to a different member directly from the Edit Transactions panel. This makes it possible to correct member assignments on existing transactions without deleting and re-entering them.

### Fixed

- Adding a transaction manually or importing transactions from a CSV file now correctly applies the selected member to those transactions. Previously, the member assignment was ignored, causing transactions to be attributed to the wrong member.
- Certain transaction or asset data containing empty values could cause the app to crash in some views. These crashes no longer occur when empty values are present in imported data.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v8.7.2_windows.zip`
   - **Mac:** `pages_app_v8.7.2_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v8.7.2_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v8.7.2_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
