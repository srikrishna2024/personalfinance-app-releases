# PersonalFinance App v7.1.2 — Release Notes

**Released:** 2026-06-02

---

## What's New

### Fixed

- Pages now launches and runs correctly on Windows systems where folder or file paths contain short (8.3-style) names. Users who previously encountered errors starting the app on certain Windows configurations should no longer see those issues.
- The app can now be started directly as a standalone setup on Windows without requiring additional steps. This makes the initial installation process more straightforward for users setting up Pages for the first time.
- The app now supports IPv6 network addresses when launching. Users on networks that use IPv6 connectivity can now open Pages without connection errors at startup.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v7.1.2_windows.zip`
   - **Mac:** `pages_app_v7.1.2_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v7.1.2_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v7.1.2_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
