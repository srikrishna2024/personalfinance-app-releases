# Northstar v8.13.4 — Release Notes

**Released:** 2026-07-16

---

## What's New

### Added

- When importing SSY (Sukanya Samriddhi Yojana) data, the import screen now shows a count of new entries versus existing ones, and includes an option to overwrite existing records. This makes it easier to understand what will change before confirming an import.
- When you manually correct a scheme mapping during a mutual fund import, the associated ISIN is now saved as an alias for that scheme. Future imports that encounter the same ISIN will resolve it automatically, reducing the need to fix the same mapping again.

### Fixed

- The mutual fund PDF import screen now retains your parsed data if you navigate away and return to the page. Previously, leaving the page would lose the parsed results and require re-uploading the file.
- The scheme-matching process during PDF import now uses saved ISIN aliases when looking up funds, and treats "balanced" as a stronger signal when disambiguating between similar scheme names. This reduces the number of schemes that fail to match automatically.
- During PDF import, the fuzzy or unresolved scheme rows are now shown separately rather than displaying the full list of all entries. This makes it quicker to identify only the rows that need your attention.
- Labels and layout in the PDF import flow have been clarified: the member name now appears in the action button, the historical data section has a clearer heading, and the pre-date section label has been updated to reduce ambiguity. Duplicate detection in the pre-date section has also been made more lenient to avoid flagging valid entries as duplicates.
- A fix was applied to how scheme names are standardised when inserting records during a mutual fund import, and skipped entries are now handled in a separate step. This prevents certain imports from failing silently or inserting data under inconsistent names.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v8.13.4_windows.zip`
   - **Mac:** `pages_app_v8.13.4_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v8.13.4_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v8.13.4_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
