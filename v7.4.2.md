# PersonalFinance App v7.4.2 — Release Notes

**Released:** 2026-06-14

## What's New

### Fixed

- The app now handles financial data series more reliably when information is partially unavailable. Users are less likely to encounter unexpected errors or blank sections on pages that display account history or trends.
- A connection issue that could cause resources to go unreleased in the background has been resolved. This reduces the chance of slowdowns or instability during longer sessions.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v7.4.2_windows.zip`
   - **Mac:** `pages_app_v7.4.2_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v7.4.2_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v7.4.2_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
