# PersonalFinance App v7.4.0 — Release Notes

**Released:** 2026-06-13

---

## What's New

### Added

- A benchmark explainer is now available as part of the app's outreach materials. This gives users additional context for understanding how their portfolio compares to relevant benchmarks.
- An outreach email template has been added to support the annual fund review process. Users going through an annual review will find relevant communication materials ready to use.

### Changed

- The annual fund review process has been updated with improvements to its logic and calculations. Users working through a review should find the process more consistent and reliable.
- Email formatting and content for the annual review have been improved. Emails generated during the review process should be clearer and better organized.
- The launcher now has a single Start/Stop button, status updates that do not block interaction, and a fix for browser handling. This makes starting and stopping the app more straightforward and reduces friction when launching.
- The home page structure has been updated to reflect a new page layout. Users may notice changes to how the home page is organized and which pages are accessible from it.

### Fixed

- Minor bug fixes and UI improvements have been applied across the app. Users may notice small inconsistencies or rough edges that have been resolved.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v7.4.0_windows.zip`
   - **Mac:** `pages_app_v7.4.0_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v7.4.0_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v7.4.0_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
