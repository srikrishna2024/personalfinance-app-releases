## How to Upgrade

1. Download `pages_app_v0.3.1.zip`
2. Extract into your existing install folder (overwrite when prompted)
3. Restore your `.env` file if it was overwritten
4. Apply any schema changes:
   ```
   python 1_Admin_Tools/run_migrations.py
   ```
5. Restart the app

> **First install?** Follow `GETTING_STARTED.md` from the top.

## Verify Your Download

After extracting the zip, run:
```
python 1_Admin_Tools/verify_integrity.py
```

Expected fingerprint for `checksums.sha256`:
```
37295efa05e4897c2e4798a7b09f28d357f038675ee882f55318039e17fe5b18
```

If the fingerprint does not match, do not use this copy — re-download from the official link.
