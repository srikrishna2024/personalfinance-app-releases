# PersonalFinance App v6.1.2 — Release Notes

**Released:** 2026-05-22

---

## What's New

### Added
- Dev Launcher: grouped admin script runner for developers, now runs scripts in-UI instead of launching a separate terminal window
- Bug report page: searchable page selector, writes to `bug_reports.log`, and includes download and app log instructions
- Styled disclaimer box on Home page, positioned below the version line
- `pip-audit` added to requirements

### Changed
- `VERSION` is now read dynamically at runtime on the Home page
- `Home.py` is regenerated automatically as part of the version bump commit
- Admin scripts run in-UI rather than spawning external terminal windows
- Updated `build_dist.py` docstring to accurately reflect Zig/compiler behaviour per platform

### Fixed
- Duplicate home emoji and icon removed from sidebar navigation
- File logging suppressed during pytest runs to prevent test mock errors polluting `app.log`
- Forced UTF-8 stdout in `diagnose.py` and Dev Launcher subprocesses to correctly handle arrow characters on Windows
- Temporary `.bat` file used for Dev Launcher to avoid Windows `start`/`cmd` quoting issues; file self-deletes after the command window closes
- Empty title added to `start` command so quoted paths are not misread as the window title
- Default path scan falls back to repo root when Enter is pressed without input in `requirements.py`
- Download link split into separate Windows and Mac placeholders in welcome email
- `_COMPILED_EXT` used in dry-run output; dead `_check_nuitka()` function removed

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v6.1.2_windows.zip`
   - **Mac:** `pages_app_v6.1.2_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v6.1.2_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v6.1.2_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
