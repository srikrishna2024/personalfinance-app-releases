# PersonalFinance App v7.3.11 — Release Notes

**Released:** 2026-06-09

---

## What's New

### Changed

- Portfolio analysis has been updated with improvements to how your holdings are evaluated. If certain fund data is temporarily unavailable, the app will now fall back to an alternative source so your portfolio view continues to load.

- The annual fund review tool has been updated to handle larger sets of fund data and includes additional analysis and visualisation features. Error handling has also been improved, so the tool is less likely to fail silently when something goes wrong during processing.

- The blog has been updated with new content.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v7.3.11_windows.zip`
   - **Mac:** `pages_app_v7.3.11_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v7.3.11_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v7.3.11_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
