# Northstar v8.5.0 — Release Notes

**Released:** 2026-06-26

---

## What's New

### Added

- **Asset Class and Tax Type are now shown as separate breakdowns** in the portfolio analysis view. Previously combined into one view, they are now split so you can see your holdings grouped by asset class independently from how they are taxed.
- **A "Where to Start" guide is now available in MF Portfolio Analysis.** This helps new users understand how to navigate the section without needing to explore it by trial and error.
- **A deep-dive guide for AFR (Asset & Fund Review) has been added**, along with help text updates across related sections. This gives users more context when reviewing their fund and asset data.

### Changed

- **Portfolio Analysis has been renamed to MF Portfolio Analysis.** The new name more clearly reflects that this section is specific to mutual fund portfolios.
- **The migration banner now directs you to the Setup Wizard** instead of Admin Tools. This makes the onboarding path clearer for users setting up or migrating their data.

### Fixed

- **EPF, PPF, and NPS holdings are now correctly categorised in the Net Worth Tracker**, and Provident & Pension Funds are shown as a separate slice in the pie chart. Previously, these were grouped under Mutual Funds (Debt), which caused misleading breakdowns of your net worth.
- **Tax type labels now display in plain language** in the Asset Class & Tax Type tab. Previously, some entries showed raw database values or blank labels due to unhandled missing data.
- **Tax classification for funds now follows the full post-budget 2024 rules**, with a fund-type tax rate reference table available in an expandable section. The earlier warning banner has been removed now that the correct rules are applied.
- **Portfolio charts are now easier to read**, with the x-axis clipped to the relevant data range and captions added to explain rolling windows. This reduces visual clutter when reviewing historical performance.
- **A data issue in goal mappings has been fixed** that could cause manual entry records to be dropped from results. Users who manually entered goal-linked transactions should now see complete data.
- **A fix has been applied to net worth double-counting** that could cause certain holdings to appear inflated in summary views.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v8.5.0_windows.zip`
   - **Mac:** `pages_app_v8.5.0_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v8.5.0_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v8.5.0_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
