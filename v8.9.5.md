# Northstar v8.9.5 — Release Notes

**Released:** 2026-07-05

---

## What's New

### Fixed

- Goal calculations now correctly separate data between members rather than mixing it together. Users with multiple members on their account will see goal progress figures that reflect each member's own activity only.
- Importing a member's tag, restoring member data, and calculating net invested using the FIFO method now work as expected. Users who rely on these features should no longer encounter missing tags, incomplete restores, or incorrect net invested figures.

---

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v8.9.5_windows.zip`
   - **Mac:** `pages_app_v8.9.5_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v8.9.5_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v8.9.5_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
