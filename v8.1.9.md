# Northstar v8.1.9 — Release Notes

**Released:** 2026-06-23

---

## What's New

### Added

- The Other Assets and Other Income tabs now include summary tables that consolidate your data at a glance. This makes it easier to review totals across entries without scrolling through individual rows.

### Fixed

- A banner that incorrectly appeared under certain fallback conditions has been suppressed. Users who encountered this banner when no action was required will no longer see it.
- After reassigning a split transaction to a different goal, the Split tab now correctly displays the consolidated row instead of showing stale session data. This ensures the view accurately reflects your changes immediately after reassignment.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v8.1.9_windows.zip`
   - **Mac:** `pages_app_v8.1.9_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v8.1.9_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v8.1.9_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
