# PersonalFinance App v7.1.3 — Release Notes

**Released:** 2026-06-02

---

## What's New

### Added

- A first-run setup assistant is now available on macOS, matching the setup experience already available on Windows. Mac users setting up Pages for the first time can follow the same guided process to get the app running without manual configuration steps.

### Fixed

- The setup assistant now starts the database automatically on launch, checks whether the required port is accessible, and displays an amber warning bar if something needs attention. Users are less likely to encounter a silent failure or a blank screen when opening Pages for the first time.

- The setup assistant now creates the necessary database user account after completing the initial configuration steps. This fixes an "authentication failed" error that some users encountered the first time they launched Pages after setup.

- The setup assistant now saves the database connection details correctly so the app can connect immediately after setup completes. Previously, users could finish setup and still find that Pages was unable to connect to the database.

- The setup assistant now detects an existing configuration and shows only the AI consent step instead of presenting the full setup form again. Users who re-run setup after already completing it will no longer be asked to re-enter information they have already provided.

- The setup assistant now prepares its own isolated Python environment before installing dependencies, and bundles the required database connectivity libraries within it. This reduces the chance of setup failing due to missing or incompatible libraries on the user's machine.

- Database backups now correctly locate the restore tool on Windows, including installations using PostgreSQL 18 and non-standard install paths. Users on Windows should no longer see backup or restore operations fail due to the restore tool not being found.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v7.1.3_windows.zip`
   - **Mac:** `pages_app_v7.1.3_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v7.1.3_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v7.1.3_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
