# PersonalFinance App v7.2.2 — Release Notes

**Released:** 2026-06-04

---

## What's New

### Changed

- Equity data is now imported and processed using an updated format. Users with equity holdings in their portfolio should see their data load and display more reliably.

### Fixed

- Several issues affecting portfolio holdings have been addressed, including a fix to how holdings data is displayed. Users should see their portfolio holdings reflected more consistently.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v7.2.2_windows.zip`
   - **Mac:** `pages_app_v7.2.2_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v7.2.2_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v7.2.2_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
