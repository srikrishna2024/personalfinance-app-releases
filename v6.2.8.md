# PersonalFinance App v6.2.8 — Release Notes

**Released:** 2026-05-26

---

## What's New

### Added

- Pages can now identify and track properties you are interested in buying. This makes it easier to keep your buying activity organised in one place.

### Changed

- The email you receive when consenting to AI features has been updated. The content of this email has been improved to communicate more clearly.
- When interest is identified in a property, an email can now be generated to support that process. This gives you a record of your buying interest directly in your inbox.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v6.2.8_windows.zip`
   - **Mac:** `pages_app_v6.2.8_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v6.2.8_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v6.2.8_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
