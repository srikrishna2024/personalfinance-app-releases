# Northstar v8.5.3 — Release Notes

**Released:** 2026-06-27

---

## What's New

### Fixed

- **Net Worth Tracker now classifies mutual funds in more detail.** Mutual fund holdings are broken down into richer categories, giving you a clearer picture of how your investments are distributed across fund types.

- **NPS Total Invested figure no longer includes fund management charges or scheme switches.** Previously, the Total Invested amount shown for your NPS account was inflated by these non-investment transactions. The figure now reflects only the money you have actually contributed.

- **The app no longer crashes on launch for users doing a fresh install.** A missing component caused some fresh installations to fail immediately on startup. This has been resolved so the app opens normally after a clean install.

---

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v8.5.3_windows.zip`
   - **Mac:** `pages_app_v8.5.3_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v8.5.3_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v8.5.3_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
