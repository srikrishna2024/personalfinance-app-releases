# Northstar v8.1.7 — Release Notes

**Released:** 2026-06-22

---

## What's New

### Changed
- The retirement planner has received user interface improvements. These changes make the retirement planning experience cleaner and easier to navigate.

### Fixed
- An issue with the financial independence check has been corrected so that other assets are no longer incorrectly included in the calculation. This ensures the check reflects a more accurate picture of the relevant figures.
- Errors that occur during income data migration are now surfaced to the user instead of failing silently. This makes it easier to identify and resolve problems if something goes wrong during that process.

---

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v8.1.7_windows.zip`
   - **Mac:** `pages_app_v8.1.7_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v8.1.7_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v8.1.7_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
