# Northstar v8.0.0 — Release Notes

**Released:** 2026-06-19

---

## What's New

### Added
- Pages now supports multiple user accounts. Households or shared devices can maintain separate profiles within a single installation.

### Changed
- The user interface has been updated. Navigation and on-screen controls have a refreshed appearance.

### Fixed
- The annual fund review no longer fails when processing certain date formats. Users who previously encountered errors during their fund review will find it completes successfully.
- The retirement planner now handles calculations correctly for certain age groups where results were previously incorrect. Affected users will see updated figures in their retirement projections.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v8.0.0_windows.zip`
   - **Mac:** `pages_app_v8.0.0_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v8.0.0_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v8.0.0_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
