# Northstar v8.13.2 — Release Notes

**Released:** 2026-07-16

---

## What's New

### Fixed

- Importing fund data from Karvy Excel files now parses dates correctly. Previously, some dates in these files could be read incorrectly, which may have caused transactions to appear on the wrong date in your portfolio history.

- Fuzzy search no longer incorrectly downgrades funds when their name contains words that strongly identify the fund type. This means fund search results should better reflect the fund you are looking for, particularly when searching by type-specific terms.

---

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v8.13.2_windows.zip`
   - **Mac:** `pages_app_v8.13.2_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v8.13.2_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v8.13.2_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
