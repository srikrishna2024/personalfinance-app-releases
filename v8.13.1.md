# Northstar v8.13.1 — Release Notes

**Released:** 2026-07-15

---

## What's New

### Added

- Investment planning now includes a Manual mode, with user-friendly descriptions for each planning option. Users who prefer to set their own allocation can now do so directly, with a glide-path recommendation shown alongside their chosen allocation and a warning displayed when their selection deviates significantly from the recommendation.
- Debt handling now offers a partial auto-deduction option. This gives users more flexibility in how debt repayments are applied when managing their financial plan.

### Fixed

- Importing an SSY (Sukanya Samriddhi Yojana) CSV file could fail silently or produce incorrect results due to a missing piece of account information being passed during the import process. The import now works correctly, and the goal selection step has been separated from the file parsing step for a more reliable experience.
- Balanced Advantage and Dynamic Asset Allocation funds were being classified as equity funds. These funds are now categorised correctly, so users will see them reflected accurately in their portfolio breakdown.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v8.13.1_windows.zip`
   - **Mac:** `pages_app_v8.13.1_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v8.13.1_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v8.13.1_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
