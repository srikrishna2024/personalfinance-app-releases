# PersonalFinance App v6.1.12 — Release Notes

**Released:** 2026-05-22

## What's New

### Fixed

- Checksum generation now runs against the distribution build rather than the source repository, ensuring integrity verification passes for buyers
- Eliminated redundant caching of shared functions in `Tax_Corner.py` that were being wrapped twice
- Moved `portfolio_stocks` table creation into database migration 0019, preventing DDL from running on the page and improving reliability of schema setup
- Added a guard against empty results in the category risk/return tab to prevent crashes when no data is returned

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v6.1.12_windows.zip`
   - **Mac:** `pages_app_v6.1.12_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v6.1.12_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v6.1.12_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
