# PersonalFinance App v7.0.0 — Release Notes

**Released:** 2026-05-27

## What's New

### Added

- After a successful backup, a reminder now appears in the Backup & Restore screen prompting you to store a copy of your backup offsite. This reminder is also included in the getting started guide and welcome email, so the advice is consistent from the moment you set up the app. Keeping a copy offsite protects your data if your disk fails or your machine is lost.

### Fixed

- The backup reminder wording has been updated to make clear that it applies when your disk crashes or your machine is lost. This removes any ambiguity about when offsite storage matters.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v7.0.0_windows.zip`
   - **Mac:** `pages_app_v7.0.0_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v7.0.0_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v7.0.0_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
