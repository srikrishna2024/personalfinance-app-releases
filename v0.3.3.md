# PersonalFinance App v0.3.3 — Release Notes

**Released:** 2026-05-20

---

## What's New

### Setup Wizard — Major UX Overhaul
- New **Prerequisites tab** checks Python and PostgreSQL are installed before setup begins, with inline install guides for both
- PostgreSQL install guide now explains the two database users (`postgres` superuser vs `pages_app` app user) and why both exist
- Python install guide added with collapsible step-by-step instructions
- Database credentials table shows exactly what to type in each field and why
- **App database user (`pages_app`) is now created automatically** when you click Save in the Environment Setup tab — no separate "DB Role" step needed
- AI features tab now owns the Anthropic API key — moved out of the general config form where it confused new users
- API key section includes step-by-step instructions for getting a key from Anthropic, with cost note (typical usage costs less than ₹10/month)
- Base URL field moved into a collapsed "Advanced" expander with a clear note that it is optional
- First-time checklist on the home tab updated to reflect the simplified flow

### Security & Distribution
- `shared/license.py` and `run.py` are now **obfuscated with PyArmor** in every release build — the license salt and activation flow are no longer visible in plain source
- `build_dist.py` updated with a full obfuscation step: runs PyArmor, places obfuscated files at correct paths, bundles the PyArmor runtime automatically
- `distribution_manifest.toml` now has an `[obfuscate]` section — upgrading to PyArmor Pro later only requires moving entries between sections, no code changes
- Fixed: `ANTHROPIC_BASE_URL` was hardcoded to `http://localhost:6655` (dev proxy) in `Portfolio_Analysis.py` — now defaults to the public Anthropic API
- Fixed: `.env.example` shipped with non-empty placeholder values — all fields are now blank so no dev credentials leak to buyers

### Developer Tooling
- `generate_license.py` now accepts buyer name as first argument and **auto-generates a pre-filled welcome email** saved to `generated_emails/` — just fill in the download link before sending
- `generated_emails/` folder is gitignored and excluded from release zips
- New `docs/WELCOME_EMAIL_TEMPLATE.md` — welcome email with license details, download link, setup instructions, and support scope disclaimer
- New `docs/FUTURE_DEVELOPMENTS.md` — tracks planned features including multi-LLM support (OpenAI, Gemini, Ollama)
- `bump_version.py` fixed: Windows terminal encoding error on the `←` character

### Documentation
- `GETTING_STARTED.md` fully rewritten to match the current wizard-centric setup flow — removed outdated manual `.env` editing, `CREATE DATABASE` SQL step, and terminal license prompt
- Getting Started now has 7 clear steps: Prerequisites → Unzip & Launch → Setup Wizard → Load Data → Import Portfolio → Goals → Debt Instruments
- "How to Upgrade" instructions in all release notes updated: uses full paths, explicit terminal-open instructions for Windows and Mac — no more "navigate to app folder"
- `CLAUDE.md` updated: new rule that `.env.example` must always have blank values; `generate_license.py` usage updated to include buyer name argument

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download `pages_app_v0.3.3.zip` anywhere (e.g. your Downloads folder)
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v0.3.3.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v0.3.3.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.

## Verify Your Download

Open the app and go to **Admin Tools → Trust Audit** — it verifies all files
automatically and shows a pass/fail result.

Expected fingerprint for `checksums.sha256`:
```
d50b9e134e7b35aaef329f9452fe3e51fef59615a89d287e97a34b38b33117b5
```

If Trust Audit reports a mismatch, do not use this copy — re-download from the official link.
