# PersonalFinance App v0.3.3 — Release Notes

**Released:** 2026-05-20

---

## What's New

### Setup Wizard — Easier First-Time Setup
- New **Prerequisites** tab confirms Python and PostgreSQL are installed before you begin, with step-by-step install guides for both
- Database setup is now a single step — fill in your credentials and click **Save & Configure Database**; the app user is created automatically, no separate step needed
- The credentials table shows exactly what to type in each field and why — no guesswork
- **AI features** tab now handles the Anthropic API key with a step-by-step guide on how to get one (takes 2 minutes, costs less than ₹10/month for typical use)
- Base URL field moved into an Advanced section — most users never need to touch it

### Security
- License activation logic is now protected — the validation code is no longer visible in plain source in the distributed app

### Bug Fixes
- Fixed: AI features were silently routing through a developer proxy URL instead of the public Anthropic API — this could cause AI features to stop working after an upgrade

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download `pages_app_v0.3.3.zip` anywhere (e.g. your Downloads folder)
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v0.3.3.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v0.3.3.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
