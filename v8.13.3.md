# Northstar v8.13.3 — Release Notes

**Released:** 2026-07-16

---

## What's New

### Fixed

- Mutual fund transactions from CAMS PDF imports now use the fund's official name from master data, looked up by ISIN. Previously, the name printed in the PDF could differ from the canonical fund name, causing mismatches with existing holdings.

- CAMS PDF imports no longer skip transactions for funds with "Balanced Advantage" (or similar names containing the word "balance") in their name. Affected transactions will now appear correctly after re-importing your statement.

- Cancelled transactions are now automatically excluded across all import formats. You no longer need to manually remove them after importing a statement.

- An error that occurred when applying fixes in the data quality editor on certain text fields has been resolved. The editor now completes the operation without crashing.

- The Help page has been updated to remove duplicate entries and correct navigation labels that no longer matched the current app structure. The page should now be easier to follow when looking up how to complete a task.

## How to Upgrade

**Use `upgrade.py` — never extract the zip manually.**
It preserves your `.env` (database credentials, license key, API key) and runs
any new database migrations automatically. Your portfolio data is untouched.

1. Download your platform zip anywhere (e.g. your Downloads folder):
   - **Windows:** `pages_app_v8.13.3_windows.zip`
   - **Mac:** `pages_app_v8.13.3_mac.zip`
2. Open a terminal:
   - **Windows:** press `Win + R`, type `cmd`, press Enter
   - **Mac:** press `Cmd + Space`, type `Terminal`, press Enter
3. Run the upgrade command (replace the paths with your actual locations):

   **Windows:**
   ```
   python C:\pages_app\upgrade.py C:\Users\You\Downloads\pages_app_v8.13.3_windows.zip
   ```
   **Mac:**
   ```
   python ~/pages_app/upgrade.py ~/Downloads/pages_app_v8.13.3_mac.zip
   ```
4. Restart the app when it prints **"Upgrade complete."**

> **Tip:** Keep a copy of your `.env` file somewhere safe as a general backup.
> If you ever need to reinstall from scratch, it has everything you need.

> **First install?** Follow `GETTING_STARTED.md` from the top.
